The responsive React/TypeScript interface prototype, supplied cave background with subtle single-plane parallax, raccoon identity, adapted alert component, three synthetic promotion scenarios, ordered findings, source dialogs, locally saved sample reviews, in-memory profile, and separately approved demonstration form navigation and filling.

TypeScript/production build and four rule tests passed. Desktop and compact browser checks are recorded in VERIFICATION.md. Reference captures are in docs/images/. The independent design review's three accessibility corrections were marked resolved.

## Start here

1. Clone or download this repository from your GitHub account.
2. Install Node.js compatible with the locked Vite version. The development machine used Node 26.8.1.
3. Open a terminal inside the downloaded project folder.
4. On Windows run `npm.cmd ci`, then `npm.cmd run dev`. On macOS/Linux use `npm ci`, then `npm run dev`.
5. Open the local URL printed by the server.
6. Run `npm.cmd run build` and `npm.cmd test` on Windows (omit `.cmd` elsewhere).

No API key is required for this interface preview. Dependencies are downloaded on the new machine. Your previous browser's locally saved sample reviews/preferences and in-memory profile do not migrate with Git.
